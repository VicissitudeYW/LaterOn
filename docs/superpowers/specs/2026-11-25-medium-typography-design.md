# 扩展 Medium 字体切片

用户于 2026-11-25 批准实施。本切片仅调整字体，延续现有视觉、字号、尺寸、颜色、间距与交互。

- 首选 `PingFang SC`，其次 `Microsoft YaHei`，再使用系统无衬线字体。
- 普通界面文案使用字重 500；现有更粗标题、按钮等保持层级。装饰性加号不作为文案加粗。
- 覆盖收藏库、设置、侧栏启动与运行状态、引导、项目选择器、编辑弹窗及扩展通知。
- 原生输入控件继承界面字重；Shadow DOM 浮层独立声明字体以隔离网站样式。
- 仅引用已安装字体，不分发字体文件，不增加网络字体依赖。
- 验证中文、英文、长文本、窄侧栏及缺少首选字体的回退；不修改被收藏网站正文排版。

浏览器渲染检查在隔离上下文运行，不操作日常浏览器资料；它不能代替已安装扩展的端到端验收。
